Use the `moon query affected` sub-command to query for all affected projects and tasks based on the
state of the workspace and VCS.

```shell
# Return affected
$ moon query affected

# Return affected including all of their dependents
$ moon query affected --dependents deep
```

This will output a map of projects and tasks as JSON. The output has the following structure:

```ts
{
	projects: Record<Id, AffectedState>,
	tasks: Record<Target, AffectedState>,
}
```

### Options

- `--dependents <DEPTH>` - Include the dependents of affected projects and tasks. Supports "none"
  (default), "direct", "deep", or a number of hops.
  <VersionLabel version="3.0.0" />

> Included dependents are marked as affected by the dependency they were reached through, in their
> `dependencies` field. The `--dependencies` option is not supported, as the output can only contain
> affected projects and tasks.
> [Learn more about graph depth](../../concepts/affected#graph-depth).
