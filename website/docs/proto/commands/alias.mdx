The `proto alias <tool> <alias> <version>` (or `proto a`) command will define a custom alias that
maps to a specific version for the provided tool. Aliases can be used anywhere a version is
accepted.

```shell
$ proto alias node work 16.16
```

By default this will update the [closest](../config#closest) `.prototools` file, starting from the
current directory and traversing upwards. Pass `--to` to customize the location.
<VersionLabel version="0.63.0" />

### Arguments

- `<tool>` - Type of tool.
- `<alias>` - Name of the alias. Supports alphanumeric chars.
- `<version>` - Version to map to the alias.

## Options

- `--to` - [Location of `.prototools`](../config#locations) to update. Supports `closest`
  (default) <VersionLabel version="0.63.0" inline />, `global`, `local`, and `user`.
  <VersionLabel version="0.41.0" />
