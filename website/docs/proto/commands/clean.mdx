The `proto clean` command can be used to uninstall stale and unused tools, plugins, and more. By
default, it will remove items that haven't been used in the last 30 days.

```shell
$ proto clean
```

Furthermore, the command can be used to target a specific artifact type.

```shell
$ proto clean plugins
```

> Cleaning stale tools does _not_ remove records from [lockfiles](../lockfile), as
> the version may still be required by a configuration, or in use on other machines.

### Trust records<VersionLabel version="0.63.0" />

The `trust` target removes [trust](../config#trust) records for configuration files and directories
that no longer exist. This is important, as a record for a deleted path would otherwise trust a
_different_ repository that is cloned to the same path in the future.

```shell
$ proto clean trust
```

Unlike other targets, this is not based on age, so `--days` has no effect. These records are also
removed when cleaning everything (the default).

### Arguments

- `[target]` - Type of target. Accepts `cache`, `plugins`, `temp`, `tools`, or `trust`
  <VersionLabel version="0.63.0" inline />. Defaults to everything. <VersionLabel version="0.44.0" />

### Options

- `--days` - Number of days before a tool is considered stale.
- `--json` - Print the clean result in JSON format. <VersionLabel version="0.44.0" />
- `--yes` - Avoid and confirm all prompts.
